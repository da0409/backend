**接口文档**

**通用说明**

接口地址（比赛原型）：<https://api.timecapsule.example.com/v1>

本地联调：<http://localhost:8080/v1>

鉴权方式：请求头携带 Authorization: Bearer {token}，登录后获得。

统一响应格式：所有接口返回 code、msg、data 三段结构，code=1 表示成功，其他值为业务错误码。

分页参数：列表类接口统一支持 page（页码，默认 1）与 pageSize（每页条数，默认 10，最大 100）。

时间格式：日期时间字段统一为 yyyy-MM-dd HH:mm:ss，仅日期字段使用 yyyy-MM-dd。

**时间胶囊管理**

**创建时间胶囊**

**基本信息**

请求路径：/capsules

请求方式：POST

接口描述：该接口用于创建一条绑定地图POI的地点时间胶囊。用户上传历史照片或视频、填写问题并设置期望回答时间范围；素材需先通过素材上传接口获取URL。

**请求参数**

格式：application/json

参数说明：

| 参数名          | 类型    | 必填 | 说明                                                                                  |
| --------------- | ------- | ---- | ------------------------------------------------------------------------------------- |
| title           | string  | 是   | 胶囊标题，例如"2025年挂下的许愿牌还在吗"                                              |
| question        | string  | 是   | 想问未来旅行者的问题                                                                  |
| poiId           | string  | 是   | 绑定的地图POI标识                                                                     |
| poiName         | string  | 否   | POI名称，用于展示                                                                     |
| lng             | number  | 否   | POI经度，地理围栏匹配用                                                               |
| lat             | number  | 否   | POI纬度，地理围栏匹配用                                                               |
| mediaList       | array   | 否   | 历史照片/视频素材列表，元素含 mediaId、caption；type 和访问URL由服务端根据mediaId获取 |
| answerBeginTime | date    | 是   | 期望回答开始日期                                                                      |
| answerEndTime   | date    | 是   | 期望回答截止日期                                                                      |
| blurFace        | boolean | 否   | 是否在AI处理时对人脸进行模糊，默认 true                                               |

请求参数样例：

```
json
{
  "title": "2025年挂下的许愿牌还在吗",
  "question": "一年后这块许愿牌是否还在原地？上面的字还清晰吗？",
  "poiId": "poi_1001",
  "poiName": "玉龙雪山·云杉坪",
  "lng": 100.1789,
  "lat": 27.1156,
  "mediaList": [
    {
      "type": "IMAGE",
      "mediaId": "m_20260924001",
      "caption": "挂许愿牌的位置"
    }
  ],
  "answerBeginTime": "2026-10-01",
  "answerEndTime": "2027-10-01",
  "blurFace": true
}
```

**响应数据**

参数格式：application/json

参数说明：

| 参数名         | 类型   | 说明                                                            |
| -------------- | ------ | --------------------------------------------------------------- |
| code           | int    | 状态码，1 表示成功                                              |
| msg            | string | 提示信息                                                        |
| data.capsuleId | string | 创建成功的时间胶囊ID                                            |
| data.status    | string | 胶囊状态：WAITING 待回信 / ANSWERED 已收到回信 / EXPIRED 已过期 |

响应数据样例：

```
json
{
  "code": 1,
  "msg": "success",
  "data": {
    "capsuleId": "cap_20260924001",
    "status": "WAITING"
  }
}
```
